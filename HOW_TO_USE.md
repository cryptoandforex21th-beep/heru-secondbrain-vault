## 📱 2. Cara Mengakses & Memerintahkan dari HP (Saat Laptop Mati Total)

### Cara Utama: Google NotebookLM (Second Brain Paling Cerdas)
1. Buka browser **Microsoft Edge** di HP Anda.
2. Masuk ke alamat: [**notebooklm.google.com**](https://notebooklm.google.com).
3. Login menggunakan akun Google Anda: `heruardiansyahtwo003@gmail.com`.
4. Buat notebook baru bernama **"SecondBrain Saya"**.
5. Klik **"Add Sources" (Tambah Sumber)** -> Pilih **Google Drive** -> Centang file `PROFILE.md` dan catatan-catatan Anda.
6. **Pasang di Layar HP:**
   * Di menu Microsoft Edge di HP (titik tiga di bawah/atas), pilih **"Tambahkan ke Layar Utama" / "Add to phone"**.
   * Sekarang NotebookLM menjadi aplikasi di layar HP Anda!
7. **Kapan pun Anda ingin berpikir, riset, atau tanya catatan:** Buka dari HP, ketik pertanyaan Anda. Dia akan menjawab berdasarkan isi catatan SecondBrain Anda secara mendalam.

### Cara Alternatif: Aplikasi Gemini di HP
1. Buka aplikasi **Gemini** di HP.
2. Anda bisa langsung bertanya:  
   `"@Google Drive cari catatan proyek di folder SecondBrain saya"`  
   Gemini Advanced otomatis membaca file di Google Drive 5TB Anda.

## 🌐 3. Cara Membuka di ChatGPT & Claude Kapan Saja

### Di ChatGPT:
1. Buka ChatGPT (di HP atau web).
2. Di kolom chat, klik tombol tanda plus (**`+`**).
3. Pilih **"Connect Google Drive"**.
4. Pilih file atau folder SecondBrain Anda. ChatGPT langsung mengenali isi catatan Anda tanpa perlu Anda jelaskan ulang!

### Di Claude:
1. Buka [claude.ai](https://claude.ai) -> Menu **Projects** -> Buat Project **"SecondBrain"**.
2. Salin isi file `00_system/PROFILE.md` ke bagian **Project Instructions**.
