# 📋 CARA MEMINDAHKAN / MENYAMBUNGKAN SECONDBRAIN KE CHATGPT & CLAUDE
> **Panduan Praktis untuk Pemula:** Simpan panduan ini. Kapan pun Anda ingin menggunakan ChatGPT atau Claude, ikuti langkah cepat di bawah ini tanpa perlu menjelaskan diri Anda lagi dari awal.

---

### OPSI 1: Cara Paling Mudah di ChatGPT (Web / HP)
1. Buka [chatgpt.com](https://chatgpt.com) atau aplikasi ChatGPT di HP Anda.
2. Klik foto profil Anda di pojok kiri bawah / kanan atas -> Pilih **Settings (Pengaturan)** -> **Personalization (Personalisasi)** -> **Custom Instructions**.
3. Di kolom **"What would you like ChatGPT to know about you to provide better responses?"**:
   * Salin isi dari file: `d:\SecondBrain\00_system\PROFILE.md` (Bagian 1 dan 2).
4. Di kolom **"How would you like ChatGPT to respond?"**:
   * Masukkan kalimat ini:
   > *"Bertindaklah sebagai asisten pribadi SecondBrain saya. Terapkan prinsip komunikasi to-the-point, ramah pemula, dan buat setiap ringkasan atau ide dalam format Markdown yang rapi agar siap saya simpan ke SecondBrain saya."*
5. Klik **Save**. Selesai! ChatGPT sekarang sudah mengenali Anda selamanya.

---

### OPSI 2: Cara Paling Nyaman di Claude (Claude Projects)
1. Buka [claude.ai](https://claude.ai) di browser.
2. Di menu samping kiri, klik **Projects** -> Buat Project baru bernama **"SecondBrain Saya"**.
3. Di bagian **Project Instructions**, salin dan tempel seluruh isi file:
   * `d:\SecondBrain\00_system\PROFILE.md`
4. Di bagian **Project Knowledge**, Anda bisa mengunggah file-file catatan penting dari folder `d:\SecondBrain\01_knowledge\`.
5. Setiap kali Anda ingin riset mendalam dengan Claude, cukup buka Project tersebut. Claude otomatis memahami konteks hidup dan proyek Anda.

---

### OPSI 3: Melalui Web App Antigravity (Paling Canggih & Otomatis)
Jika Anda menggunakan Web App SecondBrain yang kita buat:
* Anda tidak perlu copy-paste manual sama sekali.
* Cukup pilih tombol Admin: **[Gemini]**, **[Claude]**, atau **[GPT]** di atas layar chat.
* Sistem Antigravity akan otomatis menyisipkan file `PROFILE.md` dan catatan SecondBrain ke model mana pun yang Anda pilih.
