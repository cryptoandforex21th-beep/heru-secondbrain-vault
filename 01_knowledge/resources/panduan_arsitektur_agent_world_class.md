## 1. 🤖 Devin AI: Autonomous Execution & Self-Verification Loop
Devin AI adalah pionir agen software engineer mandiri. Inti dari kekuatannya bukan sekadar kecerdasan bahasa, melainkan **protokol verifikasi mandiri** (*autonomous loop*):

### A. Pola Kerja 4-Langkah (PEVR Loop):
1. **Plan (Rencana Terarah):** Pecah instruksi besar menjadi 2–4 subtugas konkret sebelum menyentuh file apa pun.
2. **Execute (Eksekusi Mandiri):** Gunakan tools (edit file, jalankan skrip terminal) tanpa menunggu konfirmasi berulang untuk hal-hal sepele.
3. **Verify (Uji & Verifikasi Sendiri):** Sebelum menyatakan "selesai", jalankan pengujian atau periksa output log. Jika ada error, perbaiki sendiri (*self-heal*) tanpa panik.
4. **Report (Lapor Hasil Akhir):** Berikan laporan ringkas yang fokus pada *apa yang berubah* dan *bukti bahwa hasil sudah berfungsi*.

## 2. ⚡ Cursor Agent: Surgical Precision & Minimal-Diff Rule
Cursor terkenal dengan kecepatannya dalam mengedit kode dan dokumen tanpa merusak struktur lain:

### Prinsip Utama:
* **Surgical Edit (Bedah Presisi):** Jangan pernah menimpa ulang seluruh file jika hanya mengubah 5 baris. Gunakan penggantian terarah (*targeted chunk replacement*) untuk menjaga integritas file dan menghemat memori.
* **Context Preservation:** Jaga struktur indentasi, komentar, dan gaya penulisan asli pemilik file.
* **Zero Assumption:** Jangan berasumsi fungsi atau library sudah ada jika belum diverifikasi di sistem.

## 3. 🎨 Lovable & v0: Design Engineering untuk GradiEnt Studio
Diambil dari prompt internal v0 dan Lovable untuk rancang bangun website arsitektur dan portofolio modern:

### Standar Estetika:
* **Whitespace & Ritme:** Berikan ruang bernapas yang cukup antar-komponen (*generous padding & margins*).
* **Palet Warna Taktil:** Terapkan konsistensi warna brand GradiEnt Studio (`--paper`, `--ink`, `--accent terracotta`, `--blueprint cyan`).
* **Tipografi Hirarkis:** Padukan serif taktil (*Cormorant Garamond*) untuk judul dengan sans-serif fungsional (*IBM Plex Sans*) untuk tubuh teks.
* **Responsive by Default:** Setiap komponen harus luwes di layar desktop maupun layar smartphone.
